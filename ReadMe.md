# 🎮 Platformer Workshop

This project is a beginner-friendly platformer game built with **HTML Canvas + Vanilla JavaScript**.

It was designed as a workshop to teach:
- Game loops
- Player movement & gravity
- Collision detection
- Camera systems
- Rendering with images (sprites + tiles)
- Basic game mechanics (coins, win condition)


---
## 🚀 Get Started (IMPORTANT)

👉 Do **NOT** start from this branch.

Instead:

### 1. Go to the workshop branch:
👉 `WORKSHOP-READY`

### 2. Then either:
- **Fork the repo** (recommended for teens)
- OR create your own branch from `WORKSHOP-READY`

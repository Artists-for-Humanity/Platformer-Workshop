# 🎮 Platformer Workshop (Starter)

Welcome! In this workshop, you will build your own platformer game step by step using **Canvas and JavaScript**.

---

## 🧠 What You’ll Learn

- How a game loop works
- Drawing to the canvas
- Gravity + jumping physics
- Collision detection
- Camera movement
- Rendering images (sprites + tiles)

---

## 🚀 Setup

1. Clone or fork this repo
2. Open the folder
3. Create an `index.html` file
4. Open `index.html` in your browser using the go live button in your bottomr right corner of VS code

---

## 🧩 How This Workshop Works

This project is broken into steps:

### Follow the files / instructions in order:

- `01.md`
- `02.mdr`
- `03.md`

---

## 🛠 Rules

- Try each step before looking ahead
- Break things down / TYPE everything out (seriously,  that’s how you learn)
- Ask questions if something feels confusing

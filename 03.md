<summary><strong><h1> 🎥 01: Add a Camera System </h1></strong></summary>

Right now everything is drawn at its exact position.

👉 That means no scrolling.

---

### Add this at the top:

```js
const camera = {
  x: 0
};
```

---

### Update camera position inside your game loop:

```js
camera.x = player.x - canvas.width / 2;
```

---

### What this does

👉 Keeps player centered
👉 World will now scroll

⚠️ But nothing will move yet until we apply the camera offset

<details>
<summary><strong><h1> 🧠 02: Apply camera to PLAYER and PLATFORMS </h1></strong></summary>

add `-camera.x` to the platforms and player x positions
#### Platforms

```js
function drawGround() {
  for (let platform of platforms) {
    ctx.fillStyle = "green";
    ctx.fillRect(platform.x - camera.x, platform.y, platform.width, platform.height);
  }
}
```

---

#### Player

```js
function drawPlayer() {
  ctx.fillStyle = "blue";
  ctx.fillRect(player.x - camera.x, player.y, player.width, player.height);
}
```

---

### Why this works

We’re NOT moving the world.

We’re shifting what we draw:

> “pretend the camera is sliding over the level”

---

👉 This is how almost every 2D game works

</details>

### Draw coins: 

Put this under where you drew your platforms and player functions

```js
function drawCoins() {
    for (let coin of coins) {
      if (!coin.collected) {
        ctx.fillStyle = "gold";
        ctx.beginPath();
        ctx.arc(coin.x - camera.x, coin.y, coin.size / 2, 0, Math.PI * 2);
        ctx.fill();
      }
    }
  }
```

and make sure to call it in your `gameLoop()`

```js
drawCoins();
```

---

### What this is

👉 Just like platforms , but circles instead of rectangles

<details>
<summary><strong><h1> ⚡ 04: Coin Collision </h1></strong></summary>

Add score:

```js
let score = 0;
```

---

### Collision check:

```js
for (let coin of coins) {
  if (!coin.collected) {
    const dx = player.x + player.width / 2 - coin.x;
    const dy = player.y + player.height / 2 - coin.y;
    const distance = Math.sqrt(dx * dx + dy * dy);

    if (distance < coin.size) {
      coin.collected = true;
      score++;
    }
  }
}
```

---

### What’s happening

👉 We check how close player is to coin
👉 If close enough → collect it

---

This is slightly different from rectangle collision
(but still just math + if statements)

</details>

---

### Collision:

Let's add a variable to the top to check if the game is over

```js
let gameWon = false;
```

Put this in the player update function under where we counted up the score

```js
if (
  player.x < goal.x + goal.width &&
  player.x + player.width > goal.x &&
  player.y < goal.y + goal.height &&
  player.y + player.height > goal.y
) {
  gameWon = true;
}
```

---

### Display win:

```js
function gameWin(){
  if (gameWon) {
    ctx.fillStyle = "black";
    ctx.font = "40px Arial";
    ctx.fillText("YOU WIN", 300, 200);
  }
}
```

and make sure to add it to your `gameLoop()`:

```js
 gameWin();
```

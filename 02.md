
# 🕹️ README 02 — Platforms + Level System

**Goal for today:** turn your single ground into a **real platformer level** with multiple platforms you can jump between.

---

## What you’re building

- ✅ Multiple platforms (not just the one ground rectangle)
- ✅ Player can land on platforms
- ✅ Level is stored as data (arrays)
- ✅ You can easily remix / design your own level

---

## Files you will touch

* `script.js` → all updates happen here

👉 No HTML or CSS changes needed

## Tiny Vocabulary (new stuff)

* **Array**: a list of things (like multiple platforms)
* **Object**: a group of properties (x, y, width, height)
* **Looping through data**: repeating logic for multiple items

<details open>
<summary><strong><h1> 🧱 01: Replace “ground” with platforms array </h1></strong></summary>

Right now you have:

```js
const ground = {
  y: 450,
  height: 50
};
```

❌ This only gives you ONE surface

---

### Replace it with:

```js
const platforms = [
  { x: 0, y: 450, width: 800, height: 50 }, // ground
  { x: 200, y: 350, width: 150, height: 20 },
  { x: 400, y: 300, width: 150, height: 20 },
  { x: 600, y: 250, width: 150, height: 20 }
];
```

---

### What this is

Each platform is:

```js
{ x, y, width, height }
```

👉 This is EXACTLY like the wordle tiles array , just different properties

</details>

<details>
<summary><strong><h1> 🔁 02: Draw all platforms </h1></strong></summary>

Replace your ground drawing with a loop:

So you go frome this:
```js
function drawGround() {
  ctx.fillStyle = "green";
  ctx.fillRect(0, ground.y, canvas.width, ground.height);
}
```

to this: 
```js
function drawGround() {
  for (let platform of platforms) {
    ctx.fillStyle = "green";
    ctx.fillRect(platform.x, platform.y, platform.width, platform.height);
  }
}
```

---

### Why this matters

Instead of drawing ONE thing:

> we draw MANY things using a loop

👉 Same concept as creating 30 tiles in Wordle

</details>

<details>
<summary><strong><h1> ⚠️ 03: Update collision for ALL platforms </h1></strong></summary>

Replace your old ground collision with this:

```js
onGround = false;

for (let platform of platforms) {
  const isLanding =
    player.y + player.height >= platform.y &&
    player.y + player.height <= platform.y + platform.height &&
    player.x + player.width > platform.x &&
    player.x < platform.x + platform.width &&
    player.velocityY >= 0;

  if (isLanding) {
    player.y = platform.y - player.height;
    player.velocityY = 0;
    onGround = true;
  }
}
```

---

### What this does

👉 Checks collision against EVERY platform
👉 Only lands if falling from above

---

### Simplified explanation

We’re asking:

> “Is the player touching the top of this platform while falling?”

If yes:

* snap player to platform
* stop falling

---

⚠️ This is the **hardest concept today**

But notice:
👉 It’s still just **if statements + loops**

</details>

<summary><strong><h1> 🧠 04: Clean up movement (important fix) </h1></strong></summary>

Right now movement might feel weird (instant stop/start).

Replace:

```js
if (keys.left) player.velocityX = -5;
if (keys.right) player.velocityX = 5;
```

---

### With:

```js
if (keys.left) player.velocityX -= 0.5;
if (keys.right) player.velocityX += 0.5;

player.velocityX *= 0.9; // friction
```

---

### What this does

* smooth acceleration
* smooth slowdown

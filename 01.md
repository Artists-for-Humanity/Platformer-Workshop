# 🕹️ README 01 — Player + Movement + Gravity

**Goal for today:** by the end of today, you’ll have a character on screen that can move left/right and jump with gravity.

## What you’re building ( broken down )

* ✅ A canvas-based game screen
* ✅ A player block that appears on screen
* ✅ A game loop that redraws the world
* ✅ Gravity pulling the player down
* ✅ A “ground” to land on
* ✅ Collision with the ground
* ✅ Movement + jumping

## Files you will need

* `index.html` → canvas setup ( the screen )
* `style.css` → basic layout ( how it looks )
* `script.js` → all game logic ( the game logic )

## New Words

* **Canvas**: a space where we draw graphics with code
* **Game loop**: code that runs over and over (~60 times/sec)
* **Velocity**: speed + direction (movement)
* **Gravity**: constant downward force
* **State**: changing values that need to be updated (player position, speed)

```js
// grab and assign name to the elements from your html
const canvas = document.getElementById("game");

  velocityY: 0,
```

`const player` will help us keep track of the player "state": things like its size, where it is, etc

👉 This is just how we *draw* the player, but you won't see anything yet since we never cal this function. That's where we'll use game-loop

<details>
<summary><strong><h1> 🔁 05: Game Loop </h1></strong></summary>

```js
function gameLoop() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  drawPlayer();

  requestAnimationFrame(gameLoop);
}

gameLoop();
```

---

### What’s happening

This is your **first working game loop**

* requestAnimationFrame runs ~60 times per second
* Clears the screen
* Draws the player again ( this will be useful once we get into movement)

👉 For now you should now see a blue square on screen

```js
const gravity = 0.5;
```

---

Create an update function:

```js
function updatePlayer() {
```

---

Add it to your game loop:

```js
function gameLoop() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
    //add your functions

    drawGround();
    drawPlayer();

    requestAnimationFrame(gameLoop);
}
```

---

### What this means

Every frame:

* player starts to fall ( and faster since we included velocity )
* y position updates

👉 If you reload, you should now see the player falling, BUT it's falling through the ground?

<details>
<summary><strong><h1> 🟫 08: Add Ground Collision </h1></strong></summary>

```js
function updatePlayer() {
  player.velocityY += gravity;
  player.y += player.velocityY;

  // collision with ground
  if (player.y + player.height >= ground.y) {
    player.y = ground.y - player.height;
    player.velocityY = 0;
  }
}
```

---

👉 Now the player:

* falls
* lands
* stays on the ground

This is your **first collision system**

<summary><strong><h1> 🎮 09: Movement Controls </h1></strong></summary>

```js
// so you don't gain speed as you move side to side, can change if you want

const keys = {
  left: false,
  right: false,
};

document.addEventListener("keydown", (e) => {
  if (e.key === "a") keys.left = true;
  if (e.key === "d") keys.right = true;
});

document.addEventListener("keyup", (e) => {
  if (e.key === "a") keys.left = false;
  if (e.key === "d") keys.right = false;
});
```

---

Update movement:

```js
function updatePlayer() {
  // horizontal movement
  if (keys.left) player.velocityX = -5;
  if (keys.right) player.velocityX = 5;
  else player.velocityX = 0;

  player.x += player.velocityX;

  // gravity
  player.velocityY += gravity;
  player.y += player.velocityY;

  // ground collision
  if (player.y + player.height >= ground.y) {
    player.y = ground.y - player.height;
    player.velocityY = 0;
  }
}
```

---

👉 Now the player should be able to move left and right

</details>

```js
document.addEventListener("keydown", (e) => {

});
```
